# BacklogVault frontend

React 19 app built with Vite. See the [project README](../README.md) for how to run everything together, the
configuration table, and the architecture.

```bash
npm install
npm run dev       # http://localhost:5173 (expects the API on http://localhost:4000)
npm test          # Vitest and Testing Library
npm run lint      # Oxlint
npm run build     # production bundle in dist/
```
